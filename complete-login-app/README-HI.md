# Apna Account

अपने ऐप के लिए यूज़रनेम और पासवर्ड से खाता बनाएँ, वापस लॉगिन करें और लॉगआउट करें। खाते और सेशन आपके कंप्यूटर पर SQLite में रहते हैं।

## Windows पर शुरू करें

1. ZIP पर दायाँ क्लिक करें और **Extract All** चुनें। निकाले हुए फ़ोल्डर में `START-WINDOWS.cmd` और `package.json` साथ दिखाई देंगे।
2. लैपटॉप पर **Node.js 24.x** इंस्टॉल करें। [Node.js डाउनलोड](https://nodejs.org/en/download)
3. **START-WINDOWS.cmd** पर डबल-क्लिक करें। पहली बार पैकेज इंस्टॉल करने के लिए इंटरनेट चाहिए। सर्वर चलने तक वह विंडो खुली रखें।
4. ब्राउज़र में [http://127.0.0.1:3000](http://127.0.0.1:3000) खोलें। यदि आपने `PORT` बदला है, तो टर्मिनल में दिखा पता खोलें।
5. पहली बार **Signup** चुनें। 3–32 अक्षरों वाला यूज़रनेम बनाएँ। इसमें अंग्रेज़ी अक्षर, अंक और अंडरस्कोर चलेंगे। 12–200 अक्षरों का नया पासवर्ड दो बार डालें। आगे इसी खाते के लिए **Login** चुनें।

ऐप बंद करने के लिए टर्मिनल में `Ctrl+C` दबाएँ। अगली बार उसी फ़ोल्डर में **START-WINDOWS.cmd** खोलें।

## कमांड से चलाएँ

Windows में जिस फ़ोल्डर में `package.json` है, उसके एड्रेस बार में `cmd` लिखकर Enter दबाएँ। Mac या Linux पर उस फ़ोल्डर में टर्मिनल खोलें। पहली बार या पैकेज अपडेट के बाद ये कमांड चलाएँ।

```sh
npm ci
npm start
```

अगली बार सिर्फ़ `npm start` चलाएँ। यदि पोर्ट 3000 पहले से व्यस्त है, तो Windows Command Prompt में `set PORT=3001` चलाकर फिर `npm start` करें।

## डेटा और GitHub

पहले रन पर `data/app.sqlite` और `data/sessions.sqlite` बनते हैं। अपडेट या कंप्यूटर बदलते समय सर्वर बंद करके पूरा `data` फ़ोल्डर कॉपी करें। स्थानीय सेशन की कुंजी भी इसी डेटा में रहती है। पुराने संस्करण की डिफ़ॉल्ट कुंजी वाले सेशन पर अपग्रेड के बाद एक बार फिर लॉगिन करना होगा।

इस प्रोजेक्ट का अलग फ़ोल्डर या अलग GitHub रिपॉज़िटरी रख सकते हैं। सोर्स कोड के साथ `.gitignore` रखें। निजी `data`, `.env` और `node_modules` अपने कंप्यूटर पर रखें।

यह ऐप सर्वर पर लॉगिन जाँचता है। केवल `public/index.html` खोलने पर ऐप उसे चलाने की कमांड दिखाएगा। GitHub Pages स्थिर पेज परोसता है। ऑनलाइन चलाने के लिए Node.js होस्ट और SQLite के लिए स्थायी डिस्क चाहिए। [GitHub Pages दस्तावेज़](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

लोकल रन अपने कंप्यूटर के पते पर सुनता है। प्रोडक्शन में HTTPS और एक स्थायी, गुप्त `SESSION_SECRET` चाहिए। कम से कम 32 रैंडम बाइट की कुंजी अपने होस्ट के environment में रखें। `TRUST_PROXY=1` केवल तब सेट करें जब होस्ट पर एक विश्वसनीय रिवर्स प्रॉक्सी ही ऐप तक पहुँचती हो।
